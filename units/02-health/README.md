# Unit 02: Health

**Учебник:** *Mindset for IELTS*, Level 3. Начальные печатные страницы Reading / Writing / Listening / Speaking: **30 / 38 / 42 / 47**. В PDF номер страницы примерно на 2 больше.

**Фокус:** flow-chart и table completion; advantages/disadvantages essay.

## Что сохранить

- `reading/`: ответы до проверки, исправления и короткий разбор ошибок.
- `writing/`: первый вариант, замечания репетитора и исправленный вариант с понятными именами файлов.
- `listening/`: ответы и разбор после прослушивания; скрипт смотреть только после первой попытки.
- `speaking/`: аудиозапись первого и повторного ответа, при желании краткий саморазбор.
- `academic/`: Короткий текст о преимуществах и ограничениях AI feedback in education с проверяемой ссылкой.

Одна попытка = одна строка в [`../progress.csv`](../progress.csv). Сохраняйте дату и номер попытки в имени файла, например `writing/2026-10-20-task2-attempt1.md`. Цель юнита и нагрузка описаны в [`../../english-study-plan.md`](../../english-study-plan.md).
