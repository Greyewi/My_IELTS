# Vocabulary: личный словарь

Собираем незнакомые слова, выражения и трудности употребления из заданий всех юнитов, чтения статей, письменных работ и разговорной практики. Общий словарь хранится в [`words.csv`](words.csv), история проверок — в [`reviews.csv`](reviews.csv). Правила для учебных чатов закреплены в [`../AGENTS.md`](../AGENTS.md).

## Как добавить слово во время занятия

Можно написать обычным языком: **«Не знаю слово abandoned»**, **«В словарь: lay claim to»**, либо использовать короткую пометку **`?abandoned`** или **`[vocab: lay claim to]`**. Контекст из текущего задания преподаватель сохранит вместе со значением. Если без контекста значение неоднозначно, сначала уточняем его.

Преподаватель также добавляет выражения, с которыми возникла конкретная ошибка. Например, `expand a roads` показывает необходимость потренировать сочетание `widen roads`. Это не означает, что все слова выражения незнакомы. Если трудность только предполагается, запись получает статус `candidate`; её проверяем коротким вопросом. Ошибку в артикле при правильно выбранном слове разбираем в грамматике.

## Что хранится в словаре

Одна запись — одна словарная единица в конкретном значении. Для другого значения той же формы допустима отдельная запись. Формы `abandon / abandoned` обычно объединяем под словарной формой; контекст исходной формы сохраняем. Collocations и конструкции вроде `be misinformed about something` храним целиком.

| Поле `words.csv` | Значение |
| --- | --- |
| `id` | Постоянный идентификатор `v0001`, `v0002`…; при сортировке не менять. |
| `added_on`, `last_seen` | Даты добавления и последней встречи в формате `YYYY-MM-DD`. |
| `term` | Слово или устойчивое выражение. |
| `part_of_speech` | Например, `noun`, `verb`, `adjective`, `verb phrase`. |
| `meaning_ru`, `definition_en` | Перевод и краткое английское объяснение значения в данном контексте. |
| `example_en` | Короткий пример с естественным употреблением. Пример преподавателя не считается ответом ученика. |
| `source_file` | Путь от корня проекта; несколько источников разделять `; `. Для слов из чата без файла оставить пустым и описать источник в `notes`. |
| `source_context` | Короткий фрагмент исходного текста или ответа ученика. |
| `evidence` | `user_reported` — пользователь отметил трудность; `observed_usage_gap` — конкретная ошибка употребления; `suspected_gap` — предположение для проверки. |
| `status` | `candidate`, `learning`, `active` или `paused`. |
| `review_step` | Шаг интервала 0–4; у непроверенного кандидата пусто. |
| `last_review`, `next_review` | Даты последней реальной проверки и следующего повторения; у кандидата без подтверждения пусто. |
| `notes` | Наблюдаемая ошибка, различие со сходным словом, изменение статуса и другие пояснения. |

Перед добавлением ищем существующую запись с тем же значением: обновляем `last_seen`, сохраняем новые источники и наблюдения. Ранее освоенное слово при повторной ошибке можно вернуть в `learning`. CSV записываем в UTF-8; значения с запятыми и переносами оформляем по правилам CSV.

## Повторение

В начале или конце занятия выбираем до 5 слов с `next_review` не позднее сегодняшней даты. Если таких слов много, сначала берём просроченные и те, по которым были ошибки. Автоматических уведомлений здесь нет: дата определяет выбор слов при следующем занятии.

Проверки чередуем: объяснить значение в новом контексте; вспомнить английское выражение по ситуации; составить своё предложение. Сначала отвечает ученик, затем идёт обратная связь. Упражнения и развёрнутые ответы можно сохранять в `practice/YYYY-MM-DD-review.md`.

Каждый фактический ответ записываем отдельной строкой в `reviews.csv`:

| Поле | Значение |
| --- | --- |
| `date`, `word_id` | Дата ответа и ID из словаря. |
| `mode` | `meaning`, `recall` или `production`. |
| `response` | Исходный ответ ученика. |
| `score` | `0` — не вспомнил / неверно; `1` — частично верно; `2` — верно в рамках конкретного задания. |
| `assisted` | `yes` / `no`: были ли подсказки или просмотр ответа. |
| `work_file` | Путь к сохранённой работе от корня проекта; для ответа только в чате допустимо пустое поле. |
| `notes` | Обратная связь и условия проверки. |

**Начальный ритм повторений:** при добавлении подтверждённого пробела ставим `learning`, `review_step = 0`, `next_review` через 1 день. После самостоятельного ответа с `score = 2` увеличиваем шаг на один, максимум до 4: интервалы для шагов 0 / 1 / 2 / 3 / 4 — **1 / 3 / 7 / 14 / 30 дней** от фактической даты ответа. При `score = 0` или `1`, либо при подсказке, возвращаем шаг 0 и повторение через 1 день. Это стартовое правило нашего журнала, которое можно менять по результатам.

`active` означает, что значение распознаётся и выражение самостоятельно употреблено в подходящем новом контексте, причём две успешные проверки разнесены минимум на 7 дней и включают `production`. Один удачный ответ или чтение перевода этого не подтверждает. При повторной ошибке возвращаемся к `learning`. Для слов `active` продолжаем периодические проверки; `paused` временно исключает слово из очереди без удаления истории.

## Прогресс

Отдельно отслеживаем количество слов в `learning` и `active`, результаты отсроченных проверок и успешное употребление в собственных работах. Рост общего числа записей сам по себе не означает рост владения языком. Проверки с подсказками и самостоятельные попытки учитываем раздельно.

Первые записи взяты из уже сохранённых работ Unit 1: они отражают наблюдавшиеся трудности употребления, а не доказанное незнание этих слов. Проверок повторения пока нет.
